# NumPy and Pandas

Practice the data foundations used in AI projects:

- Work with arrays and vectorized operations using NumPy.
- Load, inspect, clean, transform, and summarize datasets with Pandas.
- Perform exploratory data analysis and prepare features for modeling.

Run the examples from the repository root with:

```sh
python "AI Foundations/NumPy and Pandas/001_numpy_array_basics.py"
python "AI Foundations/NumPy and Pandas/002_pandas_ticket_analysis.py"
```
