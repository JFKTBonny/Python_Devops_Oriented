# Statistics and Machine Learning

Build the foundations for training and evaluating models:

- Review descriptive statistics, probability, distributions, and sampling.
- Train baseline supervised and unsupervised models.
- Use train/validation/test splits and appropriate evaluation metrics.
- Compare results and look for overfitting, bias, and data leakage.

The examples use the synthetic ticket dataset in `Final Project/data/`.
Run them from the repository root with:

```sh
python "AI Foundations/Statistics and Machine Learning/001_ticket_statistics.py"
python "AI Foundations/Statistics and Machine Learning/002_classification_metrics.py"
```
