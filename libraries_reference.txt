PYTHON LIBRARIES REFERENCE
=========================

This reference covers the Python standard-library modules and third-party
packages imported by the repository's Python examples, plus packages declared
in dependency manifests. Most examples are independent; install only the
packages needed for the example you want to run. The AI Foundations examples
share dependencies listed in "AI Foundations/requirements.txt"; its test
dependencies are in "AI Foundations/requirements-dev.txt".

STANDARD LIBRARY
----------------

argparse       Builds command-line interfaces and parses command-line options.
asyncio        Provides asynchronous programming primitives and event loops.
csv            Reads and writes comma-separated value files.
datetime       Creates, parses, and performs calculations with dates and times.
email          Builds email messages and MIME message content.
getpass        Reads sensitive input, such as passwords, without echoing it.
hashlib        Computes cryptographic hashes and message digests.
io             Provides in-memory streams and file-like objects.
json           Encodes and decodes JSON data.
logging        Emits configurable application logs.
math           Provides common mathematical functions.
multiprocessing Runs work in separate processes and provides process coordination.
os             Interacts with operating-system features and environment variables.
pathlib        Represents and manipulates filesystem paths.
platform       Reports information about the operating system and runtime.
random         Generates pseudo-random values.
re             Searches, validates, splits, and replaces text with regular expressions.
shutil         Copies, moves, and removes files and directories.
smtplib        Sends email through SMTP servers.
string         Provides string constants and common text helpers.
subprocess     Starts and controls external programs and shell commands.
sys            Exposes interpreter and process information.
time           Reads clocks and adds delays or time-based measurements.
unittest       Provides the standard testing framework and mock utilities.
urllib         Makes HTTP requests and works with URLs and URL errors.
xml            Parses and generates XML documents.
zipfile        Reads and writes ZIP archives.
